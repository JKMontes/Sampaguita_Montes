# **Distance Calculator**

## **Description:**
### The program makes the user eneter the following measurements then calculates the final distance

## **How to Run**
### 1. Open the program in Github
### 2. Run the program
### 3. Enter the values x1, y1, x2, and y2.
### 4. Check the distance displayed on the screen

## **Input Needed**
- x1
- y1
- x2
- y2

## **Sample Output**
### Enter x1: 2
### Enter y1: 3
### Enter x2: 7
### Enter y2: 8
### The distnace between the two points is: 7.07
