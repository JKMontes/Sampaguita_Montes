# **Activity 3: Finding the Hypotenuse of a Right Triangle**

## **Description** 
- The program computes the hypotenuse of a Right Triangle

## **How to Run**
- 1. Open the program in Github.
- 2. Run the program.
- 3. Enter the values for a & b.
- 4. Check the hypotenuse displayed on the screen.

## **Input Needed**
- Enter the value for *a*
- Enter the value for *b*

## **Sample Output**
- Input the length side of *a*: 6
- Input the length side of *b*: 7
- The Hypotenuse is: 9.22
